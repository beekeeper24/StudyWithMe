# StudyWithMe Learnings

This directory stores project-specific notes for future Codex sessions.

Use it for:

- architectural decisions that should not be re-litigated;
- recurring setup or environment issues;
- domain rules that are easy to forget;
- verification commands that should be repeated for risky areas;
- security reminders for OAuth2, authorization, chat access control, notifications, and WebSocket behavior.

Do not use this directory for human-facing daily logs. Human-readable progress notes belong in dated child pages directly under `StudyWithMe` in Notion.

Keep the Notion hierarchy as `작업일지 > StudyWithMe > StudyWithMe 인수인계 문서 / dated work-log pages`.

Do not put handoff content directly in the StudyWithMe project page body. Do not create an intermediate `작업일지` folder page under StudyWithMe.
